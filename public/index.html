BUILT FOR DEVELOPERS

وصّلها في دقيقة

أمثلة جاهزة للنسخ: تيرمينال، ShareX، و AI agents.

# upload from terminal
curl -F "file=@song.mp3" -F "expiry=30d" \
  "https://minyawe-link-production.up.railway.app/api/upload"
// ShareX → Custom uploader
{
  "RequestURL": "https://minyawe-link-production.up.railway.app/api/upload",
  "FileFormName": "file",
  "URL": "$json:url$"
}
# AI agent: read /llms.txt first, then upload
curl -F "file=@report.pdf" -F "expiry=7d" \
  "https://minyawe-link-production.up.railway.app/api/upload"
